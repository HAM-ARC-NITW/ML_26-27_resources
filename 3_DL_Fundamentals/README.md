# Deep Learning Fundamentals

This section covers the core basic concepts needed to understand how neural networks learn.

## Recommended Learning Order

Follow the topics in this order:

1. [Neurons & Neural Network Basics](01_neuron_nn_basics.md)
2. [Multilayer Neural Networks](02_multilayer_neural_networks.md)
3. [Activation Functions](03_activation_functions.md)
4. [Forward & Backward Propagation](04_forward_backward_propagation.md)
5. [Training basics](05_training_basics.md)


## How to Use This Section

The recommended approach is:

**Learn → Understand the mathematics → Implement → Experiment → Summarize**

Start with the basic building block, the **neuron**, and gradually move toward how a complete neural network is trained and optimized.
Also keep up with the resources that are mentioned at the end may it be a book , another git repo or a paper. Exploring on your own is highly encouraged.
